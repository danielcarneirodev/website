# GitHub Copilot Rules

## Rules

1. **Design and Code Quality**

   - All design and new code should be beautiful and modern.
   - Ensure the design is responsive and works well on all devices.
   - Use modern HTML5 and CSS3 features.

2. **Documentation**

   - Document all changes made in the `changelog.md` file.
   - Include a brief description of the change, the date, and the author.

3. **HTML and CSS Practices**

   - Follow good HTML and CSS practices.
   - Use semantic HTML tags.
   - Keep CSS organized and use comments where necessary.
   - Avoid inline styles; use external CSS files instead.

4. **SEO Practices**
   - Follow the best SEO practices.
   - Use appropriate meta tags.
   - Ensure all images have `alt` attributes.
   - Use descriptive and meaningful titles and headings.
   - Follow the best accessibility practices.

## Example Changelog Entry

```markdown
## [Date: YYYY-MM-DD]

### Added

- Initial template setup with basic HTML structure.

### Changed

- Updated meta description for better SEO.

### Fixed

- Corrected CSS file link in the HTML template.

### Author

- Daniel Carneiro
```
